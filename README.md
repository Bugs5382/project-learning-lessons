# project-learning-lessons 📚

> 🎓 The public lesson code from my videos and site, open for anyone to use.

This repository holds the code that goes with my lessons: samples, examples and tutorial
projects you can read, run and reuse while you follow along.

## ✨ Highlights

- 🧪 **Code samples** — the working code behind each lesson.
- 🧭 **Tutorials and examples** — projects that follow the videos and the site.
- 🤝 **Open for all to use** — take what helps you and build on it.

## 🚀 Usage

Clone the repository to follow along with a lesson:

```bash
git clone https://github.com/Bugs5382/project-learning-lessons.git
```
